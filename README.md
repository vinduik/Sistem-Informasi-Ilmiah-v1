# 🎓 Sistem Informasi Ilmiah Pengumpulan Skripsi dan Tugas Akhir Mahasiswa

**Sistem Informasi Ilmiah Pengumpulan Skripsi dan Tugas Akhir Mahasiswa** merupakan aplikasi berbasis web yang dirancang untuk mendukung proses pengumpulan, pengelolaan, pengarsipan, dan dokumentasi karya ilmiah mahasiswa, khususnya skripsi dan tugas akhir.

Sistem ini bertujuan untuk mempermudah mahasiswa dalam menyerahkan dokumen karya ilmiah secara digital serta membantu pengelola program studi maupun institusi pendidikan dalam melakukan pengelolaan dan pemantauan dokumen secara terstruktur, sistematis, dan terintegrasi.

## 🎯 Tujuan Pengembangan

1. Mempermudah proses pengumpulan skripsi dan tugas akhir mahasiswa secara online.
2. Meningkatkan efektivitas pengelolaan dokumen karya ilmiah.
3. Mendukung digitalisasi administrasi akademik.
4. Mempermudah pencarian dan penelusuran arsip karya ilmiah.
5. Meningkatkan keamanan dan keteraturan penyimpanan dokumen akademik.

## ✨ Fitur Sistem

- **Manajemen Mahasiswa** — Pengelolaan data mahasiswa yang melakukan pengumpulan karya ilmiah.
- **Pengumpulan Karya Ilmiah** — Fasilitas unggah dokumen skripsi dan tugas akhir secara digital.
- **Manajemen Dokumen** — Pengelolaan dokumen karya ilmiah mahasiswa.
- **Verifikasi Dokumen** — Mendukung proses pemeriksaan dan verifikasi dokumen yang dikumpulkan.
- **Status Pengumpulan** — Pemantauan status pengumpulan dokumen mahasiswa.
- **Arsip Digital** — Penyimpanan dan pengelompokan dokumen karya ilmiah.
- **Pencarian Dokumen** — Mempermudah pencarian arsip berdasarkan informasi akademik.
- **Manajemen Pengguna** — Pengelolaan akses pengguna sesuai kewenangan.
- **Laporan Pengumpulan** — Penyajian informasi dan rekapitulasi pengumpulan karya ilmiah.

## 👥 Pengguna Sistem

Sistem dirancang untuk mendukung beberapa kelompok pengguna:

1. **Administrator** — Mengelola konfigurasi dan keseluruhan data sistem.
2. **Pengelola Akademik** — Mengelola, memeriksa, dan memverifikasi dokumen karya ilmiah.
3. **Mahasiswa** — Melakukan pengumpulan serta memantau status dokumen skripsi atau tugas akhir.

## 🛠️ Teknologi Pengembangan

Bagian ini disesuaikan dengan teknologi yang digunakan dalam implementasi aplikasi.

- Backend: PHP
- Database: MySQL / MariaDB
- Frontend: HTML5, CSS3, JavaScript
- Web Server: Apache
- Development Environment: XAMPP

## 🔐 Keamanan dan Pengelolaan Dokumen

Sistem perlu memperhatikan keamanan data mahasiswa dan dokumen akademik, termasuk:

- Pembatasan akses berdasarkan hak pengguna.
- Validasi jenis dan ukuran file yang diunggah.
- Pengelolaan dokumen secara terstruktur.
- Perlindungan data akademik mahasiswa.
- Pencatatan aktivitas pengelolaan dokumen.

## 🚀 Manfaat Sistem

Dengan adanya sistem ini, proses pengumpulan dan pengarsipan skripsi serta tugas akhir diharapkan menjadi lebih efektif, efisien, tertib, dan mudah ditelusuri. Sistem juga mendukung transformasi layanan administrasi akademik menuju tata kelola dokumen berbasis digital.

## 📌 Status Pengembangan

Sistem ini dikembangkan secara bertahap sesuai kebutuhan pengelolaan karya ilmiah dan administrasi akademik di lingkungan perguruan tinggi.
